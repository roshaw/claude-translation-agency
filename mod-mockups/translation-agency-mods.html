Translation Agency

Mods for Translation Agency users

Six static mockups of mods — side panes, bands, status-line segments and toasts that sit beside the Claude chat and show the state of a translation run: coverage per language, the three-tier panel at work, the C1–C7 review, the glossary it enforces, the questions it logged, and the gates it must pass before delivery. Built the same way as the LayOff comeback-mods plugin (one plugin in .claude/skills/, function-hook UI, shared drawing helpers). Every number, language and string below is invented sample data. Sample run: a docs project → de · fr · ja, domain technical.

05

Open questions (queries)

bandpane

Uncertainty is handled asynchronously: when the translator is genuinely unsure, it makes its best guess and logs the question — its assumption and what it needs to know — instead of interrupting. This surfaces that log so you can answer on your own time; answering settles it for next run.

06

Delivery gates

bandpane

The last line before ship: the completeness gate (no silent gaps on a --full run) and each project gate (plagiarism, readability, compliance) per language. Nothing delivers while a gate is red — and an override is reported as overridden, never shipped silently.
