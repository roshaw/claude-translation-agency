# Phase 6 — GitHub Copilot CLI port notes

Output: `.github/agents/<name>.agent.md` — both worker agents and skills (Copilot's unit is the
agent). Generated by `npm run build:agents`; guarded by `npm test` (Layers 1–3).

## Verified against current docs (Sept 2026)

- **Agent files:** `<name>.agent.md`, YAML frontmatter + markdown system prompt (≤30k chars).
  Fields used: `name`, `description` (required), `model`, `tools`, `user-invocable`.
  Source: docs.github.com/en/copilot/reference/custom-agents-configuration + the GitHub blog
  "custom agents in GitHub Copilot CLI".
- **Delegation:** an agent invokes another via the **`agent` tool** — so the Claude
  `Agent({ subagent_type })` maps to "the agent tool ({ agent: … })". Workers are `user-invocable:
  false`; skills stay user-invocable.

## Seam substitutions (adapters/copilot.json)

- **Paths (seam 4):** each `.claude/agents/<n>.md` → `.github/agents/<n>.agent.md`; each
  `.claude/skills/<x>/SKILL.md` → `.github/agents/<x>.agent.md`.
- **Spawn (seam 2):** `Agent({ subagent_type: … })` → `the agent tool ({ agent: … })` (no backticks,
  so inline-code spans stay valid); `(Agent tool)` → `(the agent tool)`.
- **Tool names (seam 3):** `WebSearch`/`WebFetch` → "web search/fetch"; `TaskCreate…` → "a task
  checklist"; `AskUserQuestion` → "an interactive question".
- **Frontmatter (seams 1/5):** rebuilt per unit; model from `tiers.json` (Copilot's Anthropic models,
  so "Opus/Sonnet/Haiku" prose stays accurate); `tools: ["*"]`.

## Friction / known refinements

- **No `/slash` commands.** Copilot CLI invokes agents by selection, not `/name`. We deliberately
  **left `/translate…` refs unchanged** in the bodies (they read as logical command names) rather than
  mangle the `## Invocation` flag examples via literal substitution. A real hand-port would reword
  those examples to "invoke the translate agent with …". This is the entry-point (seam 4) friction for
  Copilot — cosmetic, flagged for a live-run pass.
- **Coarse tool grant.** `tools: ["*"]` grants all tools. Fine-grained restriction (junior =
  read/edit/search/shell only) is a pending refinement — Copilot's tool-alias vocabulary isn't fully
  documented beyond `read`/`edit`/`search`/`agent`, and we won't emit alias names we can't verify.
- **Model IDs** in `tiers.json` (`claude-opus-41`, etc.) are placeholders — re-verify at port time.
- **Layer 5 (live run)** on the Copilot CLI against `examples/eval-fixture/` remains the pre-release
  manual step.
